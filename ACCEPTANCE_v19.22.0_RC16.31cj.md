# Akseptanse RC16.31cj

- [x] Eksakt Webmotors-søk bruker Commander 2.2 turbodiesel-varianten.
- [x] Mobiauto bruker valgt Ceará- eller Brasil-rute, ikke fast São Paulo-rute.
- [x] Eksplisitte pagineringslenker følges på samme nettsted, maksimalt fire sider per kildesøk.
- [x] Blokkerte og endrede kilder vises fortsatt som ufullstendig kontroll, ikke null treff.
- [x] Manuelle annonselenker kan lagres og overvåkes hvert 15. minutt.
- [x] Samme bil beholder identiteten ved prisendring.
- [x] Første pris, forrige pris, ny pris, tidspunkt og en begrenset prisbane lagres.
- [x] Vesentlig prisfall gir grønn nedpil med kroner og prosent.
- [x] Vesentlig prisøkning gir rød opppil med kroner og prosent.
- [x] Ny annonse og ny beste kandidat har egne fargede symboler.
- [x] Samme bil på ny kilde varsles uten duplikatflom.
- [x] En annonse varsles som borte først etter to komplette kontroller av dens egne kilder.
- [x] En blokkert kilde kan ikke skape et falskt «solgt/fjernet»-varsel.
- [x] En tidligere borte annonse varsles når den publiseres igjen.
- [x] Pushover viser tidligere og ny pris, første funn og første pris.
- [x] Utstyr kan gjenkjennes fra annonsetekst: elektrisk bakluke/passasjersete, panoramatak, ADAS og syv seter.
- [x] Manglende chassisnummer, servicehistorikk og garanti vises som kontrollpunkter, ikke som bekreftede feil.
- [x] Bruker kan angi transport- og dokumentkostnad; estimert totalsum vises uten å late som dette er et pristilbud.
- [x] Treffkort har eksplisitt mørk bakgrunn og lys tekst i mørk visning.
- [x] Bilmodulen er fortsatt isolert fra investering, rapporter, læring og handel.
