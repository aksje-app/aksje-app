# Deploy RC16.31i

1. Legg inn FULL-pakken som komplett kilde, eller kopier DELTA-innholdet over RC16.31h.
2. Deploy én gang og vent til tjenesten er `Live`.
3. Kontroller toppteksten: `v19.22.0-rc16.31i`.
4. Åpne Autonomi → beslutnings-/ordrespor og kontroller den første nye beslutningen mot feltene i akseptansedokumentet.
5. Kontroller at eldre beslutninger fortsatt viser sin opprinnelige identitet.
6. Hvis produksjonsbindingen allerede er egendefinert, skal den stå urørt; dette er tilsiktet.

Det kreves ingen sletting eller manuell databaseendring.
