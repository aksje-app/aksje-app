# Akseptanse RC16.31c

1. Versjon skal vises som `v19.22.0-rc16.31c`.
2. Ingen testserie skal starte uten ny eksplisitt aktivering i denne versjonen.
3. Faste rapporter skal vises og leveres kun 08:00, 14:00 og 22:00 Europe/Oslo.
4. Paper-status skal få nytt heartbeat ved neste cron; vellykket skannedato endres bare etter reell skann.
5. Prioritert vurderingsrekkefølge skal vise 1–3 kandidater når kandidater er analysert, med faktisk utfall.
6. Retensjonsstatus skal være COMPLETED uten sletting av portefølje eller handler.
