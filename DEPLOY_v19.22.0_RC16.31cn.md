# Deploy RC16.31cn

1. Pakk ut den rene deltaen over RC16.31cm.
2. Deploy samme kilde/commit til web og scheduler.
3. `EXPECTED_APP_VERSION` trenger fortsatt ikke endres.
4. Åpne Jeep Commander 2.2 og kjør «Test DataForSEO uten varsler» én gang.
5. Åpne «DataForSEO-diagnose – se hva som ble funnet og forkastet».
6. Ta skjermbilde av tabellen eller trykk «Last ned sikker diagnose-ZIP» og last ZIP-en opp i samtalen.
7. Ikke aktiver automatisk DataForSEO før både OLX og Webmotors er grønne.
