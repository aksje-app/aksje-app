# F3 – oppfølging med separate NOK-perioder

Etter den første revisjonen valgte oppdraget separate NOK-regnskaper for Paper
Trading, Autonomi og Superporteføljen. Felles basisvalutamotor er nå utvidet med
dokumenterte åpninger, sperrede utkast, eksplisitt godkjenning, kostnadsfordeling,
atomisk fulljournal, avstemming og rapporter. Superfond beholder sitt native
NOK-regnskap og får en direkte regnskapskontroll.

Se [overgangsplan og kontrakter](../f3-20261023/OVERGANG.md) og
[ny sluttrapport](../f3-20261023/rapport.md). Den første revisjonens testtall og
rapport gjelder sitt daværende commit og erstatter ikke den nye sluttkjøringen.

Ingen produksjonsportefølje er overført eller aktivert. Åpningsbevis og
kontrollert kobling til ordinær utførelseskilde må foreligge før produksjonsbruk.
Gamle modellresultater og tap beholdes; manglende transaksjoner konstrueres ikke.

Neste fase er dokumentert i [produksjonsavstemming og overgangsprøve](../f3-avstemming-20261023/rapport.md). Den skiller manglende produksjonskilder fra beståtte programvaretester og beskriver nye dokumenterte regnskapshendelser.
