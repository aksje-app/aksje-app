# Akseptansekontroll v19.22.0-rc16.20

- [ ] Ny kjøring viser ny kjørings-ID umiddelbart.
- [ ] Prosent, aktivt steg og siste reelle fremdrift er synlige.
- [ ] Heartbeat kan bevege seg uten at «siste reelle fremdrift» feilaktig flyttes.
- [ ] Stillstand over 60 sekunder gir tydelig varsel og sikker frigivelsesknapp.
- [ ] PREFLIGHT uten fremdrift blir `STALLED` senest etter 150 sekunder.
- [ ] Etter frigivelse kan ny kjøring startes uten serverrestart.
- [ ] Gammel worker kan ikke endre status til `COMPLETED` senere.
- [ ] Diagnosepakke kan lastes ned og inneholder ikke API-nøkler eller porteføljedata.
- [ ] Vanlig fullført kjøring ender på 100 % og lagrer rapport.
- [ ] «Kjøring og fremdrift» viser jobben uten å laste tunge rapport- og analysepaneler.
- [ ] Kjøps-/salgs-/porteføljekriterier er uendret.
