- Stabil 512 MiB Paper-scanner med avgrensede cacher og varig gjenopptak.
- Ingen reduksjon i markeder, tickere, datakilder eller analyseomfang.
- Midlertidig tickerkarantene stopper gjentatte døde oppslag og utløper automatisk.
- Foreløpige rapporter revalideres etter én time; endelig R2 varsles.
- Kort PDF forklarer det komplette tekniske vedlegget og bruker konsistent shortstatus.
- Læringsvarsler kan ikke forveksles med reelle kjøp eller ordre.

Produksjonsgrenser, score-, risiko-, portefølje- og handelsregler er uendret.
