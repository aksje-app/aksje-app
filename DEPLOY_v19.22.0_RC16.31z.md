# Deploy RC16.31z

1. Deploy FULL, eller DELTA over verifisert RC16.31y.
2. Restart Render web og cron; kontroller `v19.22.0-rc16.31z`.
3. Start én full utkastkjøring for Norge, Sverige og USA.
4. Kontroller at kjøringen går forbi marked 59/59 og fullfører Autonomi og rapport.
5. Last ned diagnosepakken og kontroller aktuell RSS, topp-RSS og cgroup-margin før Autonomi.
6. Kontroller PDF, teknisk vedlegg/komplett rapportpakke, historikk og Pushover-lenke.
7. Rull tilbake til RC16.31y dersom prosessen fortsatt erstattes eller rapportintegriteten feiler.
