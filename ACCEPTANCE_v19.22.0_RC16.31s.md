# Akseptanse RC16.31s

1. APP_VERSION er `v19.22.0-rc16.31s` med RC16.31r som direkte forgjenger.
2. En offentlig rapporttoken utløser aldri automatisk toppnavigasjon.
3. Rapportsiden tilbyr PDF i ny fane, lokal nedlasting og retur til programmet.
4. Retur til programmet fjerner rapporttokenet ved å gå til rotadressen.
5. Ugyldig eller manipulert URL kan ikke injisere HTML-attributter.
6. Full aktiv testsamling har 0 feil; historiske strict-xfail forblir dokumenterte.
7. FULL, DELTA, deploynote, valideringsrapport, endringsinventar og SHA-256 følger leveransen.
8. Endelig produksjonsstatus krever live mobiltest fra Pushover til rapport og tilbake til appen.
