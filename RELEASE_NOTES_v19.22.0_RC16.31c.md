# RC16.31c

- Stopper gamle 4/4-testserier automatisk ved ny programversjon.
- Faste rapporter kan bare kjøre 08:00, 14:00 og 22:00 (Europe/Oslo).
- Revalidering er stille og lager ikke nye Pushover-varsler.
- Prioritert vurderingsrekkefølge viser inntil tre analyserte kandidater uten å kalle dem kjøpsanbefalinger.
- Paper-scanner får låst reservekjøring dersom egen worker ikke har heartbeat.
- Daglig, konservativ retensjon begrenser reproduserbare rapport- og sporingsartefakter.

Portefølje, handler, beslutninger, innstillinger og revisjonsspor slettes ikke av retensjonen.
