# v19.22.0-rc16.18

- Rapporter åpner som standard i «Hurtigarkiv og komplett ZIP».
- Hurtigarkivet returnerer før scheduler, manuelle jobber, historikk, Accuracy Analytics, Drift, jobbprofiler og rapportkropper kjøres.
- ZIP-startknapp og livestatus står alene med kun lett metadata for de 20 nyeste rapportene.
- Ingen rapport-JSON, PDF, tekst, kjøringsspor eller leveransedata lastes i hurtigarkivet.
- «Fullt rapportsenter» er fortsatt tilgjengelig som et eksplisitt arbeidsområde.
- Callback-start, statuspolling, watchdog, prosessisolasjon, timeout og karantene er beholdt.
