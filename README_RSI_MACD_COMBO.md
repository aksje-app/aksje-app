# RSI + MACD Combo Signal

Nytt:
- RSI nivå 3 visualisering:
  - gjeldende RSI-boks
  - retning ↑/↓
  - momentumstyrke
  - overkjøpt/oversolgt-soner
  - RSI nå-label på høyre side

- RSI + MACD combo:
  - BUY når RSI snur opp fra lav sone og MACD bekrefter
  - SELL når RSI er høy/snur ned og MACD svekkes
  - HOLD/BULLISH når RSI er sunn og MACD bullish
  - eget panel under grafen med combo signal og confidence

Dette er inkludert sammen med resten av filene i pakken.
