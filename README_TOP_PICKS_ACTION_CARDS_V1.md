# Top Picks Action Cards v1

Endrer presentasjon av Top Picks:

- Hver aksje viser nå:
  - Total score
  - Teknisk signal
  - Handling nå: KJØP NÅ / VENT / UNNGÅ NÅ
  - Confidence
  - Risiko

- Top Picks-fanen har nå to underfaner:
  - Top Picks: beste kandidater totalt
  - Kjøp nå: kun aksjer med grønt teknisk kjøpssignal

Dette løser problemet der en aksje kunne ligge øverst i Top Picks, men samtidig ha SELL/AVOID i teknisk analyse uten forklaring.
