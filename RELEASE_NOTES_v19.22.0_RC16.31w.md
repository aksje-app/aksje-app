# RC16.31w – verifisert innsider- og shortanalyse

RC16.31w er bygget direkte fra RC16.31v.

- Svenske innsiderkategorier og utstedernavn normaliseres mot FI-registeret.
- SEC Form 4 merkes som primærkilde, duplikater mot sekundærleverandør fjernes og planlagte 10b5-1-salg nedvektes.
- Innsiderkjøp vurderes over 180 dager og salg over 90 dager.
- Faktisk shortinnhenting er koblet til den avgrensede evidenslisten for Norge, Sverige og USA.
- Ingen offentlig terskelposisjon, kildefeil, ikke støttet og ikke søkt vises separat; manglende treff blir aldri 0 %.
- Porteføljetabellen viser både Short og Innsider.
- «Full rapport med vedlegg» er primær nedlasting; ZIP-knappen beskriver eksplisitt innholdet.

Short og innsider forblir observasjon/evidens. Ingen handelsfullmakt eller produksjonsterskel er endret.
