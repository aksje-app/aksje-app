# Deploy v19.22.0-rc16.30

Installer først på Render-tjenesten **Stabilisering**. Ikke erstatt produksjon
før akseptansepunktene er bestått.

1. Last opp FULL-pakken, inkludert `assets`.
2. Bekreft `v19.22.0-rc16.30` på Stabilisering.
3. Start én manuell rapport.
4. Observer delstegene under Autonomi.
5. Kontroller PDF, Pushover og `COMPLETED`.
6. Ved feil: last ned diagnosepakken før ny kjøring.
