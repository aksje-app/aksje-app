# Signal Engine v1

Legger til felles smartere signalmotor:

- bedre BUY/HOLD/SELL
- dynamisk score basert på RSI/MACD/breakout/patterns
- forklaring: hvorfor BUY/HOLD/SELL
- kompatibel med app13 via calculate_signal_intelligence()
- trading_engine.build_trading_decision bruker samme hjerne

Endrer ikke DB, Pushover eller trading execution.
