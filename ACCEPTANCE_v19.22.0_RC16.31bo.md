# Acceptance RC16.31bo

- Kort rapport viser maksimalt 3 Fresh Trend-varsler når slike finnes.
- Kort rapport viser ticker, signal, Fresh Score, trendalder, 3d/5d og kort «Hvorfor nå?»-forklaring.
- Kort rapport merker signalene som observasjon, ikke kjøpsfullmakt.
- Teknisk vedlegg beholder full RSI/OBV/breakout/RS/støtte-motstand/evidensdetalj.
- Ingen kjøps-, risiko-, likviditets-, portefølje- eller handelsgrenser endres.
- Norge-only og eksisterende bm/bn trendfunksjoner består regresjonstest.
