# Acceptance – v19.22.0-rc16.34c

Releaseblokkere:
- Én kvalifisert aksje kan aldri få mer enn 15 % målvekt.
- To kvalifiserte aksjer kan ikke bli 50/50; resten skal være kontanter.
- Eksisterende 50 % og 33,33 % posisjoner skal bli 15 % + 15 % ved neste evaluering, med 70 % kontantandel dersom ingen andre kjøp godkjennes.
- Ingen målvekt kan overstige konfigurert `max_position_pct`.
- Daglig læringsrapport og porteføljekontroll skal være forståelige uten interne programbegreper.
- Stop-varsel skal svare på hva som skjedde og om handling kreves.
- Full regressjon må være grønn før merge.
- Live Render må verifiseres før produksjonen kan beskrives som fullt levert.
