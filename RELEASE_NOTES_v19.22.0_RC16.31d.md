# v19.22.0-rc16.31d

RC16.31d avslutter rapport- og lagringsarbeidet uten å endre handelsregler.

- Prioritert vurderingsrekkefølge viser inntil tre faktisk analyserte selskaper selv når ingen er kjøpsgodkjent. Faktisk utfall og viktigste sperre vises på samme rad.
- PDF-flyten er komprimert og verifisert uten tom ekstraside. Kildetekst, kontrollvedlegg og ansvarsfraskrivelse beholdes.
- Pushover gjentar ikke tidssonen etter planlagt tidspunkt.
- Offentlige rapportlenker som er utløpt eller falt ut av indeksen slettes av daglig vedlikehold.
- Reproduserbare kjørings-, rapport- og sporingsartefakter beholdes i kortere, faste vinduer. Rapportarkivet begrenses til 180 kjøringer.
- Lagringsvedlikehold registrerer databasebruk før og etter rydding.

Portefølje, posisjoner, handler, beslutninger, innstillinger og revisjonsspor er eksplisitt beskyttet og slettes ikke.
