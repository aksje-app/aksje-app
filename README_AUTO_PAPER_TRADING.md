# Auto Paper Trading

Denne pakken legger til full auto paper trading:

- Startkapital: 100 000 kr
- Posisjon per trade: prosent av portefølje
- Flere samtidige aksjer
- Maks åpne posisjoner
- Automatisk BUY
- Automatisk SELL
- Stop-loss
- Take-profit
- RSI-exit
- Live portefølje
- Trade-logg
- PnL

Viktig:
Bruk DATABASE_URL på både Web Service og Cron Job for felles portefølje.

Dette er simulert handel, ikke ekte penger.
