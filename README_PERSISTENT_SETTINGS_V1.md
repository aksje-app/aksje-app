# Persistent Settings v1

Legger til lagrede innstillinger som Web Service og Cron kan dele via DATABASE_URL.

Ny fil:
- settings_store.py

Lagrer:
- Auto trading av/på
- Markeder Cron skal bruke
- Maks aksjer per marked
- Min confidence / score
- Maks åpne posisjoner
- Maks trades per dag
- Posisjonsstørrelse
- Cooldown
- Pushover av/på

Trykk "Lagre auto-innstillinger" i sidepanelet etter endring.
