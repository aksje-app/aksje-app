# RC16.31cp – eksakt Webmotors-lagerfilter

- Webmotors-kilden for Hele Brasil bruker den verifiserte hovedlenken for brukt/seminy Jeep Commander 2.2 Turbo Diesel Overland AT9.
- URL-en sender eksplisitt årsintervall 2025–2026, valgt kilometergrense og side 1.
- Eksisterende kontrollerte paginering følger videre resultatsider når Webmotors leverer lesbare sidelenker.
- Hvert funn valideres fortsatt lokalt for motor, drivlinje, årsmodell og kilometer.
- DataForSEO-spørringen nevner nå den eksakte Overland AT9-varianten, mens individuell annonselenke fortsatt kreves for godkjent API-test.
- Direkte blokkering fra Webmotors skjules ikke; kildestatus og diagnose viser dette uttrykkelig.
