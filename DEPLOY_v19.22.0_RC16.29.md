# Deploy v19.22.0-rc16.29

Last opp hele FULL-pakken til GitHub, inkludert `assets`.

Etter Render-deploy:

1. Bekreft versjon `v19.22.0-rc16.29`.
2. Start én manuell rapportkjøring.
3. Kontroller at Autonomi passerer 84 prosent og går videre til Rapport.
4. Kontroller læringsaksept `PASS` og samsvarende antall læringshandler.
5. Kontroller at Pushover-lenken åpner den ferdige rapporten.
6. Last ned diagnosepakken dersom kjøringen ikke fullføres.
