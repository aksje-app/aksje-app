# RC16.32t – Innsiderkilder i Superporteføljen

- Sjekker eide aksjer og de fem høyest rangerte finalistene per marked mot offisielle primærkilder etter den brede skanningen. Maksimalt 40 aksjer, fire samtidige forespørsler. Sjekken er informativ og endrer ikke handelsbeslutninger eller stopptap.
- Leser Veidekkes offisielle børsmeldinger og PDF-vedlegg for ansattprogrammet. En transaksjon krever entydig avstemming mellom tidligere beholdning, kjøpt antall og ny beholdning.
- Dokumenterte kjøp i ansattprogrammet vises som informasjon med nøytral innsidervurdering. Ukjente eller tvetydige vedlegg gir ingen bekreftet transaksjon.
- Oppbevarer cache for primærkildesjekk separat fra sekundære dataleverandører. Tidligere retting av tilbakeknapp og utskriftsvisning fra RC16.32s følger med.

Begrensning: spesialisert vedleggslesing gjelder foreløpig VEI.OL. Andre norske børsnoterte selskaper beholder Euronext-kontroll med eksplisitt status for meldinger som ikke kan struktureres.
