# Driftsforutsetninger – v19.22.0-rc16.34r

Ingen deploy eller merge er utført i denne revisjonen.

Bruk Python 3.12.13 og requirements.lock. Kjør tools/verify_dependency_lock.py
og tools/check_runtime_dependencies.py før oppstart. Render-konfigurasjonen
ligger i render.yaml; produksjon krever separat kontrollert PostgreSQL og
leverandørtilganger. Lokal utvikling bruker isolert APP_RUNTIME_ROOT.

Økonomisk åpningsbalanse kan ikke etableres ved å omdøpe eldre modellandeler
til faktiske aksjer. Originale valutakurser, kostnader og transaksjonsbevis må
avstemmes før en ny regnskapsperiode med basisvaluta tas i bruk.
