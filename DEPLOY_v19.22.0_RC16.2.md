# Deploy v19.22.0 RC16.2

1. Erstatt RC16.1 med RC16.2 FULL.
2. Bekreft banner `v19.22.0-rc16.2`.
3. Åpne Autonomi -> Rapporter.
4. Start ett utkast.
5. Ikke oppdater nettleseren manuelt.
6. Bekreft at prosent, aktivt steg og oppdatert-tid endres innen 5-10 sekunder.
7. Bekreft at siden ikke blir stående nedtonet.
8. Bekreft at Oversikt fortsatt oppdaterer fremdrift som før.

Rollback: deploy RC16.1 FULL dersom Rapporter ikke oppdaterer automatisk eller Oversikt får regresjon.
