# Kurs på graf og nivåer

Nytt:
- Gjeldende kurs vises til høyre på prisgrafen
- Gjeldende kurs vises også i teknisk analyse-graf
- Signal alerts viser:
  - Gjeldende kurs
  - Motstand
  - Støtte
  - Avstand i prosent fra gjeldende kurs til støtte/motstand

Dette gjør det enklere å se hvor nær aksjen er støtte/motstand.
