# Akseptanse RC16.31h

Godkjent release krever:

1. Versjon vises som `v19.22.0-rc16.31h`.
2. Porteføljeavkastning i kroner og prosent bruker samme faktiske startverdi.
3. Endring av resetfeltet kan ikke endre historisk avkastning uten eksplisitt porteføljereset.
4. Utviklingsgrafen viser prosentutvikling og har separat kapitalfordeling.
5. Aktiveringssteg og blokkårsaker er forklart i brukerflaten.
6. Bare den eksakt kjente eldre profilen migreres automatisk; øvrige profiler og læringsparametere bevares.
7. Finansielle tabelltall viser to desimaler, mens valutavarsler viser tre.
8. Faste rapporttider, investeringsunivers, rapportmotor, Paper Trading og lagrede handler er uendret.
9. FULL og DELTA består distribusjonskontroll uten runtime-data, hemmeligheter eller ugyldige filer.
