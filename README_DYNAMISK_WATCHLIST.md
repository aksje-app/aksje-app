# Dynamisk watchlist

Denne pakken gjør watchlisten automatisk.

## Nytt
- Alle aksjer fra valgt marked kan brukes som standard watchlist
- USA/Norge/Sverige/Alle støttes
- Watchlisten følger valgt marked og antall aksjer
- Du kan fortsatt slå av dynamisk watchlist og skrive egen liste manuelt
- Scan-limit er lagt inn for ytelse, så appen ikke prøver å scanne 200 aksjer hver refresh

## Viktig
Hvis du setter auto-scan og veldig mange aksjer, blir appen tregere.
Anbefalt:
- 20–40 aksjer for vanlig bruk
- 5–20 aksjer for hyppige varsler
- 50–100 ved manuell scanning
