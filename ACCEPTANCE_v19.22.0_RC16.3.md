# Akseptanse v19.22.0 RC16.3

RC16.3 kan godkjennes lokalt når:

1. Valgt visningstidssone kan lagres og leses tilbake fra varig innstillingslager.
2. Lagring av tidssone kaller ikke helsidererender eller navigasjonsfunksjoner.
3. Aktiv side, panel og fane er uendret etter lagring.
4. Klokken viser PC-/nettlesertid og apptid, og oppdateres hvert sekund.
5. Navigasjonsrenderer har samme SHA-256 som RC16.2.
6. Scheduler-kontrakten 08:00 og 22:00 Europe/Oslo er uendret.
7. Full regresjon er grønn.

Produksjonsklar kan først erklæres etter live Render-verifisering av tidssonelagring, navigasjon, klokke, UI, PDF, JSON, logger, scheduler og Pushover.
