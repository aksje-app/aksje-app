# Clean UI-versjon

Dette er en ryddet UI-versjon uten HTML-feilen der <div> ble vist som tekst.

Nytt:
- Kurs vises direkte på hvert aksjekort
- Prosentendring vises som delta
- Bruker Streamlit-native cards/metrics i stedet for sårbar HTML
- Beholder øvrige funksjoner fra siste pakke

Last opp alle filene til GitHub og la Render deploye på nytt.
